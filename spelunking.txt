Key files:
offline.cpp
  Sets up a server with the given command line arguments.
  Then it reads the query and declaration files (i.e., set up how the stream looks like).
  Then it sends the stream of events to the server.

core_client/client.hpp
  seems to be the client that receives the events before they are sent to the server.

core_server/library/server.hpp
  receives the events and passes them to the offline_streams_listener

core_server/library/components/stream_listeners/offline/offline_streams_listener.hpp
  receives the events and passes them to the backend

core_server/internal/interface/backend.hpp
  receives the events and passes them to the quarantine_manager

core_server/internal/interface/modules/quarantine/quarantiner.hpp
  receives the events and passes them to the relevant policies

core_server/internal/interface/modules/quarantine/quarantine_policies/base_policy.hpp
  base policy is the interface for the policies
  there are two policies:
    - direct policy
    - wait fixed time policy

core_server/internal/interface/modules/quarantine/quarantine_policies/direct_policy.hpp
  direct policy is the policy that sends the events to the queries

core_server/internal/interface/modules/quarantine/quarantine_policies/wait_fixed_time_policy.hpp
  wait fixed time policy is the policy that waits for a fixed time before sending the events to the queries
  it keeps event sorted on the primary time




Detailed usage:
Usage: core [--help] [--version] [--webserver VAR] [--router VAR] [--stream_listener VAR] [--startingport VAR] --query VAR --declaration VAR [--options VAR] --csv VAR
Optional arguments:
  -h, --help             shows help message and exits 
  -v, --version          prints version information and exits 
  -w, --webserver        Port for the webserver [nargs=0..1] [default: 443]
  -r, --router           Port for the router [nargs=0..1] [default: 5000]
  -s, --stream_listener  Port for the stream listener [nargs=0..1] [default: 5001]
  -sp, --startingport    Starting port for the server [nargs=0..1] [default: 5002]
  -q, --query            Path to the query file [required]
  -d, --declaration      Path to the declaration file [required]
  -o, --options          Path to the options file [nargs=0..1] [default: ""]
  -c, --csv              Path to the csv data file [required]
